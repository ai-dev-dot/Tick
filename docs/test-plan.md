## 1. 数据层测试 (单元)

### 1.1 task_templates CRUD
```
- 创建任务模板 (所有字段必填验证)
- 更新任务模板 (内容/分类/期限/提醒)
- 软删除任务 (is_deleted=1)
- 查询未删除任务列表
- 按分类筛选任务
- 按期限类型筛选 (日常/近期/长期)
```

### 1.2 daily_records CRUD
```
- 生成今日记录 (日常-每天)
- 生成今日记录 (日常-每工作日 → 工作日/非工作日)
- 不重复生成 (已有今日记录时跳过)
- 查询今日所有记录
- 状态切换 (待完成→已完成→待完成)
- 完成时间戳记录
- 按日期范围查询统计
```

### 1.3 每日生成逻辑
```
- 打开APP触发检查
- "每天"任务：今天无记录→生成
- "每天"任务：今天有记录→跳过
- "每工作日"任务：周一→生成
- "每工作日"任务：周六→不生成
- "每工作日"任务：周日→不生成
- 不补中间空缺（昨天未生成也忽略）
```

## 2. 业务逻辑测试 (单元)

### 2.1 任务生命周期
```
- 新建日常任务→自动生成今日记录
- 新建近期任务→仅创建模板，状态待完成
- 新建长期任务→仅创建模板，状态待完成
- 删除任务→is_deleted=1，记录保留
- 删除后不在列表显示
- 删除后记录仍参与统计
```

### 2.2 筛选逻辑
```
- 全部Tab：日常置顶+近期居中+长期折叠底部
- 全部Tab：各组内未完成在上
- 日常Tab：仅显示日常任务
- 今日其他Tab：仅显示近期任务
- 长期任务不在日常/今日其他Tab出现
```

### 2.3 AI解析函数
```
- 正常输入："每天晚上10点喂小乌龟" → {content, category, deadline_type, daily_option, reminder_time}
- 近期任务："明天上午9点开会" → deadline_type=近期
- 长期任务："学习英语" → deadline_type=长期
- 每工作日："周一到周五早上7点起床" → daily_option=每工作日
- 无提醒："今天买菜" → reminder_time=null
- 异常输入：空字符串、超长字符串、纯符号
- API超时降级：返回partial结果或错误状态
- API返回非JSON：错误处理
```

### 2.4 统计计算
```
- 昨日完成率 = 昨日完成/昨日总数
- 本周完成率 = 近7天完成/近7天总数
- 本月完成率 = 近30天完成/近30天总数
- 分类完成统计 = 按category聚合
- 无数据时显示0%（不报错）
- 仅统计非删除任务的记录
```

## 3. 集成测试

### 3.1 Store → DB 集成
```
- taskStore.addTask() 写入SQLite并更新UI
- taskStore.toggleStatus() 更新数据库并刷新列表
- taskStore.deleteTask() 软删除并更新列表
- 筛选切换触发重新查询
```

### 3.2 AI Service → Store 集成
```
- AI解析成功 → 自动填充Store
- AI解析失败 → 降级手动模式，错误提示
- 用户手动修改AI预填结果后保存
```

### 3.3 通知集成
```
- 首次使用请求通知权限
- 权限授予→创建任务时设置通知
- 权限拒绝→任务正常创建，静默
- 本地通知触发内容格式验证
```

## 4. E2E 测试

### 4.1 核心流程
```
1. 空状态→FAB→创建第一个任务→返回首页→看到任务
2. 手动创建任务→填写所有字段→保存→在列表中显示
3. AI智能创建→输入"每天8点喂猫"→自动填充→手动修改分类→保存
4. 点击任务圆圈→完成→再次点击→撤销→回到待完成
5. 左滑任务→确认删除→任务消失→统计仍计入
6. Tab切换（全部↔日常↔今日其他）
7. 长按任务→选择编辑分类→修改→确认修改
```

### 4.2 边界场景
```
1. 0个任务→空状态引导显示
2. 1个日常+1个近期→正确的排序和分组
3. 10个已完成任务→全部在已完成分组
4. 周末→每工作日任务不显示
5. 快速连续点击状态切换→不产生重复更新
6. AI解析超时→手动输入降级
```
